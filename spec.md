# Specification

## Summary
**Goal:** Rebrand the website by replacing all occurrences of "Veda Botanics" with "Nature Glow" across the frontend.

**Planned changes:**
- Update the page `<title>` and meta tags in `index.html` to "Nature Glow"
- Replace brand name in the Navbar component (logo text, aria-labels, alt text)
- Replace brand name in the Footer component (brand name, tagline, copyright)
- Replace brand name on the Home page, including the hero section heading
- Replace brand name in MobileNavDrawer and AdminLayout components
- Search and replace any remaining "Veda Botanics" references across all other frontend source files

**User-visible outcome:** The entire website displays "Nature Glow" as the brand name everywhere "Veda Botanics" previously appeared, including the browser tab, navbar, homepage hero, footer, mobile nav, and admin panel.
