# Specification

## Summary
**Goal:** Rebuild the Nature Glow Ayurvedic skincare website frontend with a premium, elegant design system and rich landing page sections.

**Planned changes:**
- Add a full-page Hero section with Ayurvedic brand headline, subheadline, CTA button, botanical background image, and fade-in/slide-up animations using deep forest green, warm beige, and soft gold palette
- Build a Featured Products section with glassmorphism-style cards showing product image, name, price, and Add to Cart button with hover animations, populated via existing React Query hook
- Add a Benefits section with three icon cards (100% Natural, Chemical-Free, Handmade) on a light sage green background with scroll-triggered slide-up animations
- Create a Testimonials section with at least three customer quote cards showing name, star rating, and quote text on warm beige background
- Build an "About Ayurveda" storytelling section with two-column desktop layout, botanical image, golden accent divider, and serif/sans-serif typography
- Ensure the floating WhatsApp button appears on all customer pages, fetches the current number from backend with fallback, shows tooltip and pulse ring, and invalidates React Query cache when admin updates the number
- Design a premium Footer with brand name/logo, nav links, contact info, social media placeholders, golden divider, and copyright on a deep forest green background
- Apply a global Ayurvedic design system: colors (#0B3D2E, #F5E6D3, #C9A96E, #6B4F3A, #A8B5A2), Playfair Display/Cinzel for headings, Lato/Poppins for body, consistent whitespace, soft shadows, and rounded corners
- Ensure full mobile responsiveness across all sections with large tappable buttons and graceful typography scaling

**User-visible outcome:** Visitors see a fully redesigned, premium Ayurvedic skincare storefront with an elegant landing page, animated sections, product showcase, testimonials, and a persistent WhatsApp contact button — all looking polished on both desktop and mobile.
